## Selected Projects

### RNA-seq Software Benchmarking
First-author research benchmarking 400+ bulk RNA-seq tools to investigate how software-development practices influence tool usability, adoption, and scientific impact.

**Code:** [Mangul Lab RNA-seq repository](https://github.com/Mangul-Lab-USC/RNA-seq)

**Preprint:** [Robust software development practices improve citations of RNA-seq tools](https://doi.org/10.1101/2025.09.05.674580)

### Varenicline PBPK Modeling
Developed a physiologically based pharmacokinetic model of varenicline integrating pharmacokinetic, pharmacogenomic, and OCT2 transporter variability to investigate inter-individual differences in drug disposition.

**Code:** [Varenicline PBPK Models](https://github.com/SansSharma/Varenicline_PBPK_Models)
